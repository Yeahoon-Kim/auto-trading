# L001 — KR 12-1 모멘텀 + KOSPI 국면 필터

## 1. 타겟 시장
- 시장 / 유니버스 / 타임프레임: KR 주식 (KOSPI + KOSDAQ 전 종목, 상장폐지 포함) / 일봉, 월 1회 리밸런싱
- 이 시장을 고른 이유: `krx_1d`에 상장폐지 종목까지 있어 생존편향 없이 검증할 수 있고, 2010년부터 이력이 길다.
  첫 lab이므로 엔진이 완전히 지원하는 시장에서 단순한 고전 전략으로 엔진 자체도 함께 점검한다.

## 2. 전략 — 백테스트 실행 전에 작성하고 커밋
- 작성일: 2026-11-15
- **가설**:
  1. 투자자는 새 정보에 늦게 반응한다(과소반응·군집). 그래서 지난 1년간 오른 종목이 이후 몇 달간 더 오르는 경향(중기 모멘텀)이 있다.
     최근 1개월은 단기 반전 효과가 있어 제외한다(12-1).
  2. 모멘텀 전략은 약세장 뒤 반등 국면에서 크게 무너진다(momentum crash). 지수가 200일 이동평균 아래일 때 현금으로 빠지면
     그 손실 구간 상당 부분을 피해 위험 대비 수익이 좋아진다.
  3. 한국 시장에서는 모멘텀 효과가 미국보다 약하다는 연구가 많다. 따라서 **기각될 가능성도 충분하다**고 보고 시작한다.
     통과하지 못해도 "국면 필터가 MDD를 얼마나 줄이는가"를 기록으로 남긴다.
- 출처: Jegadeesh & Titman (1993), Daniel & Moskowitz (2016) "Momentum crashes", Faber (2007) 200일선 국면 필터
- 진입 규칙 (매월 첫 거래일 종가 기준 계산, 다음 거래일 시가 체결. 월말은 다음 거래일을 봐야 확정되므로 쓰지 않는다):
  1. 국면: KOSPI 지수 종가 > 200일 이동평균이면 투자, 아니면 전액 현금
  2. 후보: 그날 종가가 있고(거래정지 아님), 원본 종가 ≥ 1,000원, 최근 60거래일 평균 거래대금 ≥ 10억 원,
     252거래일 이상 가격 이력이 있는 종목
  3. 점수: 21거래일 전 종가 / 252거래일 전 종가 − 1 (12-1 모멘텀, 수정주가)
  4. 점수 상위 20종목을 동일 비중(각 5%)으로 보유
- 청산 규칙: 다음 달 첫 거래일 리밸런싱에서 상위 20위 밖이면 매도. 국면이 꺼지면 다음 리밸런싱에 전량 매도.
  상장폐지는 엔진이 마지막 가격 다음 봉에 청산한다.
- 포지션 크기: 동일 비중, 월중에는 비중을 되돌리지 않음 (`rebalance: on_signal` — 리밸런싱 날에만 전 종목을 목표 비중으로 맞춤)
- 파라미터: lookback 252, skip 21, top_n 20, ma_days 200, liq_days 60, min_value 10억, min_price 1,000원
- 사전에 정한 비교: 같은 기간 KOSPI 지수 보유, 그리고 국면 필터를 끈 같은 전략(참고용, 판정에는 쓰지 않음)

## 3. 백테스트 (워크포워드)

- 비용 반영: 수수료 / 세금 / 슬리피지

## 4. 유효성 검증 (labs/README.md의 고정 기준)
- [ ] 1. 시험 구간 Sharpe ≥ 1.0
- [ ] 2. 시험 Sharpe ≥ 학습 Sharpe × 0.5
- [ ] 3. 파라미터 ±20%에서 Sharpe ≥ 0.5
- [ ] 4. 비용 2배에서도 수익
- [ ] 5. 거래 수 ≥ 30
- [ ] 6. 잠금 구간 (1회만): 수익 ≥ 0, MDD ≤ 개발 구간 × 1.5
- [ ] 7. 생존편향·미래참조 점검
- 참고: 국면별 성과 (상승 / 하락 / 횡보)
