# L010 — KR 가치+수익성 결합 (B/M 순위 + 영업이익/총자산 순위)

고전 퀀트 프로그램 6번째 기법 ([docs/research/2026-11-18-classic-quant-factors.md](../../docs/research/2026-11-18-classic-quant-factors.md) 5절).
**가설·규칙은 2026-11-18, L005~L008 결과(기준 1 통과 0개, 단면 요인은 동일가중보다 우세)를 본 뒤에 커밋했다.** 규칙은 문헌·프로그램 공통값으로 고정하고 그 결과에 맞춰 고르지 않았지만, 같은 KR 개발 구간 노출이 있어 `exposed_from: [L001, L005, L006, L007, L008]`.

## 1. 타겟 시장
- 시장 / 유니버스 / 타임프레임: KR 주식 KOSPI+KOSDAQ (상장폐지 포함) / 일봉, 월 1회 리밸런싱
- 유니버스 (프로그램 공통, 사전 고정): 보통주(코드 끝 0), 원본 종가 ≥ 1,000원, 20일 평균 거래대금 ≥ 10억 원, 가격 이력 ≥ 252거래일, 그날 거래(거래량 > 0)
- 포트폴리오 (공통): 점수 상위 20%(후보 수 × 0.2, 내림) 동일가중, 매월 첫 거래일 종가로 계산 → 다음 거래일 시가 체결, `rebalance: on_signal`. 상장폐지는 엔진이 청산
- 사전에 정한 비교 (`baseline.py`): KOSPI 지수(참고) / 유니버스 동일가중 / 무작위 같은 종목 수 100회

## 2. 전략 — 백테스트 실행 전에 작성하고 커밋
- 작성일: 2026-11-18
- **가설**:
  1. 가치(싼 종목)와 수익성(돈 잘 버는 종목)은 서로 반대로 움직이는 경향이 있어, 둘을 같이 고르면 "싸면서 좋은" 종목이 남고 위험 대비 수익이 각 요인보다 좋아진다 (Novy-Marx 2013 "The other side of value", Asness·Frazzini·Pedersen QMJ, Greenblatt 마법공식).
  2. 사전 예측: L005(0.34)·L006(0.57)보다 Sharpe가 높지만 기준 1(1.0)은 못 넘을 것.
- 출처: Novy-Marx (2013), Greenblatt (2005), Asness, Frazzini & Pedersen (2019)
- 점수: 그날 후보 안에서 B/M(자본총계/시가총액, 자본 ≤ 0 제외) 백분위 순위와 영업이익 TTM/총자산 백분위 순위의 **단순 평균** (Novy-Marx 2013의 순위 합산 방식). 둘 중 하나라도 없으면 제외
- 원 논문과의 차이: GP/A 대신 영업이익/총자산 (dart_fin에 매출원가 없음, L006과 같음). 마법공식의 EBIT/EV·ROC는 현금·차입금이 없어 정식으로 못 만든다
- 데이터 시점: `fin_timing: first` (L005·L006과 같음)
- 파라미터 (공통값): quantile 0.2, min_value 10억, liq_days 20, min_price 1,000, min_hist 252. 두 순위의 가중치는 1:1 고정 (조정하지 않음)
- 워크포워드: 2017-07-01 시작 (L006과 같음) → 시험 2019-07 ~ 2026-05
