# L014 — KR 박스권 하단 지지 매수 · 상단 저항 앞 매도 (손익비 3:1 이상만)

> 사용자 아이디어 "지지와 저항 전략"(2026-11-19)의 하위 전략 2/3. 원문 요지·겹침·공통 설정은 [L013 README](../L013-kr-ma-support/README.md) 0절과 같다.
> 세 lab(L013·L014·L015)은 같은 날 같이 사전등록했다.

## 0. 사용자 원문 (이 하위 전략)
- 전고점·전저점이나 추세 안 박스 하단에서 지지·반등을 확인한 뒤 매수, 상단에서 저항을 맞고 하락하면 매도. 손익비 3:1 이상만, 손절·익절가를 정하고 진입.

### 겹침
- L003(rejected)은 쌍바닥(두 저점 뒤 사이 고점 돌파)·피보나치 반등을 봤고, "삼각형·박스"는 2차 대상으로 **시험하지 않았다**.
  같은 개발 구간을 본 차트 연구에서 나온 아이디어라 `trials.exposed_from: [L003]`.
- 새로 보는 것: 옆걸음 박스의 **하단 반등 매수와 상단 앞 익절**(돌파가 아니라 박스 안 왕복).
- 이번에 **안 하는 것**: "추세 안 박스"(기울어진 채널). 채널 정의(추세선 접점)는 L003 추세선 탐지기 영역이고 정의 선택지가 많아 다중 검정이 커진다 →
  수평 박스 결과를 보고 사용자가 정한다.

## 1. 타겟 시장
- KR 주식 `krx_1d` 전체(상장폐지 포함) 중 그날 20일 평균 거래대금 ≥ 10억 원, 원본 종가 ≥ 1,000원, 255봉 이상 이력 / 일봉. US는 [us/](us/) 참고만.

## 2. 전략 — 백테스트 실행 전에 작성하고 커밋
- 작성일: 2026-11-19
- **가설**: 옆걸음 구간에서는 지난 저점 근처에 매수 대기 주문과 "싸다"는 기억이, 지난 고점 근처에 본전 매도 물량이 모인다. 하단에서 반등을
  확인하고 사면 손절은 하단 바로 아래로 짧고 목표(상단 앞)는 멀어, 박스가 유지되는 동안은 3:1 이상 손익비가 나온다. KR 개별주의 단기 반전
  성향이 이를 돕는다.
- 반대 가설: 박스는 사후에만 보이고, 하단 터치는 박스 이탈(하락 추세 시작)과 구별되지 않는다. 승률은 손익비로 정해지는 무작위 수준에 머문다.
- 출처: 박스 이론(Darvas), 지지·저항 매매 일반.
- 진입 규칙 (봉 t 종가까지 보고, t+1 시가 진입):
  1. 박스 = 직전 60봉(t 제외)의 고가 최대(상단), 저가 최소(하단). 폭 상단/하단 − 1 ≤ 30%.
  2. 경계가 이미 확인된 옆걸음: 최근 10봉 안에 새 상단·새 하단이 없다 (상단·하단 모두 10봉보다 먼저 만들어짐).
  3. 하단 지지·반등 확인: 저가 ≤ 하단 × 1.03, 종가 > 하단, 양봉(종가 > 시가), 종가 > 전일 종가.
  4. 손절 = min(당일 저가, 하단) × 0.99.  목표 = 상단 × 0.99 (상단 저항 앞에서 판다).
  5. 손익비 (목표 − 종가) / (종가 − 손절) ≥ 3.0. 같은 날 20일 평균 거래대금 순 상위 5개.
- 청산 규칙: 손절가·목표가만 (같은 봉 둘 다면 손절, 갭은 시가). 시간 청산 없음 (엔진에 없음).
  사용자 원문의 "상단에서 저항 맞고 하락하면 매도"는 상단 1% 아래 지정 익절로 근사한다 (상단에서 꺾이는 것을 확인하고 파는 규칙은 하루 늦어 목표가보다 불리).
- 실행 유형: `type: trade`. 학습(`fit`) 없음 — 파라미터는 사전 고정.
- 포지션 크기: L013과 같음 (거래당 위험 1%, heat 10%, 종목당 10%, 동시 10종목, Kelly 안 씀, 자본 1,000만 원).
- 파라미터: `lab.yaml` `params`.

### 비교 기준 (사전등록)
L013과 같음 — 무작위 종목 위약(`placebo.py`, 시드 20, 같은 날·같은 손절/목표 비율 거리) 대비 백분위. 판정은 고정 기준 7개로만.

### 예측 먼저 (결과를 보기 전에 기록, 2026-11-19)
- **lead agent (Claude)**: 고정 기준 1 **불통과** (확신 80%). 세 하위 전략 중 가장 나을 것으로 예상(KR 단기 반전) — 시험 Sharpe 0 ~ +0.5, 승률 22~30%,
