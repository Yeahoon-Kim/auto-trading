### 예측 먼저 (결과를 보기 전에 기록)
- **lead agent(Claude)**: 학계 결과(Lo·Mamaysky·Wang 2000, Bajgrowicz·Scaillet 2012)는 "일부 패턴은 이후 수익 분포에 정보가 있지만 비용 뒤 이익은 대개 사라진다".

### A 통과 기준 (도구·패턴 × 시장 × 시간 축마다)
1. 탐색 구간에서 20봉 초과수익(신호 − 추세 맞춘 위약)이 Holm 보정 후 유의(α = 0.05). 보정 대상 = 이번 라운드의 모든 (도구 × 방향 × 시장 × 시간 축) 조합.
2. 초과수익 > 왕복 비용 (엔진 기본값 기준 KR 약 0.4%, US 약 0.6%).
3. 확인 구간에서 같은 부호이고 크기가 탐색 구간의 50% 이상.
4. 표본 ≥ 100건 (탐색 구간).

### noise floor
위약을 시드만 바꿔 20번 뽑아 초과수익 추정치가 흔들리는 폭(표준편차)을 잰다. 이보다 작은 차이는 효과로 보지 않는다.

### 데이터 구간
- 잠금 구간(실행일 기준 최근 6개월)은 A에서도 읽지 않는다 (`autotrader.backtest.data.load()` 기본 동작).
- A 단계는 개발 구간(2010-01-04 ~ 2026-05-18, 실행일 2026-11-18 기준)을 시간순으로 **탐색 50% / 확인 50%** 로 나눈다 (2026-11-18 사용자 결정).
  경계 = **2018-03-12** (신호일 기준). 20봉 뒤 수익이 경계를 넘는 탐색 구간 신호는 빼서 두 구간이 겹치지 않게 한다.
  도구 정의·파라미터는 탐색 구간에서만 정하고, 확인 구간은 라운드당 한 번 본다. (B lab은 `labs/README.md`의 워크포워드를 그대로 쓴다.)
- B lab에는 L003을 `trials.exposed_from`에 적는다. 이동평균 교차는 L002(US 상위 10 · 10/20일 교차, 대기)와 겹치므로 서로의 노출로 기록한다.

### 미리 알려진 한계
- US는 현재 구성종목만 있어 "바닥 패턴 뒤 반등"이 부풀려질 수 있다. 같은 종목 위약과 비교하면 상당 부분 상쇄되지만 완전하지 않다 → US 결과는 KR 결과의 보조로 본다.
- 패턴 정의(고점·저점의 크기, 어깨 높이 허용 오차 등)는 사람마다 다르다. 정의를 여러 개 시도할수록 다중 검정이 커지므로, 라운드 1은 문헌의 표준 정의 하나씩만 사전등록한다.
- B(신호형 lab)의 1회 주문 상한: master 7dfba5a에서 백테스트는 미적용·잘렸을 주문만 기록으로 정해짐.

## 4. 라운드 3 — 시장 국면(사이클) 통합 재점검 (2026-11-18 사용자 지시, 사전등록)

verifier·통과 기준은 라운드 1·2에서 승인된 것을 그대로 쓴다 (새 기준 없음 → lead agent가 진행, 사후 보고).

**국면 데이터**: `regime_1d`와 같은 정의(`intel/market.py` `_trend_block`·`_labels`)를 lab 안에서 2010년부터 계산한다(공식 데이터는 2015년부터라 임시, 전략팀 HQ에 연장 요청함).
관측일 다음 거래일부터 쓴다(`shift(1)`). 신용 스프레드(최근 3년만)는 뺀다.

## 2. 라운드 1 brief (subagent 공통 지시) — 2026-11-18 확정

**목표**: KR·US 일봉·주봉에서 우선 검증 도구 5종의 A0 탐지기와 A 유효성 결과를 낸다.

**사전등록 정의 (라운드 1)** — 신호일 t는 패턴이 "확정"된 봉, 진입은 t+1 시가.

| 도구 | 롱 신호 | 숏(하락) 신호 | 정의 출처 |
|---|---|---|---|
| 이동평균 | 종가가 200일(주봉 40주)선을 상향 돌파 / 50·200 골든크로스 | 하향 돌파 / 데드크로스 | 고전 (Brock·Lakonishok·LeBaron 1992) |
| 피보나치 되돌림 | 직전 상승 스윙의 38.2~61.8% 되돌림 구간에서 반등 확인(구간 안 저점 뒤 양봉 종가 > 전일 고가) | 대칭 | 고전 (스윙 = 고점·저점 탐지기 출력) |
| 헤드앤숄더 | 역HS 넥라인 상향 돌파 | HS 넥라인 하향 돌파 | Lo·Mamaysky·Wang 2000 정의 |
| 쌍·삼중바닥 | 두(세) 저점 차 ≤ 1.5%, 사이 고점 상향 돌파 | 쌍·삼중천장 대칭 | Lo·Mamaysky·Wang 2000 / Bulkowski |
| 추세선 | 하락 추세선(고점 3개 이상 접점) 상향 돌파 | 상승 추세선 하향 돌파 | 고전 |

- 고점·저점 찾기: 커널 평활 후 극값(Lo 외 2000) 또는 ATR 배수 지그재그 중 하나를 탐지기 담당이 고르고 근거를 적는다. **극값은 확정 시점까지 미래 봉을 쓰지 않는다** (잘라내기 검사로 확인).
- 유니버스: KR = 그날 기준 시가총액 상위 500 중 20일 평균 거래대금 10억 원 이상(그날 알 수 있는 값). US = `us_1d` 전체(S&P500 + Nasdaq100 현재 구성).
- 숏 신호는 "하락 예측력"으로만 본다 (KR 개별주 공매도 실전 불가 → B에서는 매도·회피 신호로 씀).

**산출물 위치**: `labs/L003-chart-patterns/` 안 (`patterns/` 탐지기, `study/` 유효성, `results/A/`). 엔진·데이터 코드는 고치지 않는다.
