# L003 — 차트 패턴 유효성 연구 → 실전 전략

> 상황판: [STATUS.md](STATUS.md) · 판단 기록: [log/](log/)
> 이 lab은 두 단계다. **A(유효성 연구)** 는 "패턴 뒤 수익률이 우연보다 나은가"를 보는 연구이고, 판정 대상 전략이 아니다.
> **B(전략화)** 는 A를 통과한 패턴마다 별도 lab(L0xx)을 만들어 `labs/README.md` 고정 기준과 validator로 판정한다.

## 0. 문제 정의 — 2026-11-18 사용자 확정

| 항목 | 내용 |
|---|---|
| 목표 | 사람들이 실제로 쓰는 차트 분석 도구·패턴을 코드로 정의해 찾고, (A) 유효성을 판정하고, (B) 살아남은 것을 비용 포함 실전 전략으로 만든다 |
| 시장 | KR 주식(`krx_1d`, 상장폐지 포함) + US 주식(`us_1d`, 현재 구성종목 → 생존편향 있음) |
| 시간 축 | 일봉 + 주봉 ("거시적 관점") |
| 우선 검증 대상 | 사용자 지인 트레이더가 주로 쓰는 도구: **이동평균선 기반, 피보나치 되돌림, 헤드앤숄더(역HS 포함), 쌍바닥·삼중바닥(쌍봉·삼중천장 포함), 추세(추세선)** |

| 완료 조건 | ① A 보고서(도구·패턴별 유효/무효 판정) ② A를 통과한 것마다 lab 판정(validator 의견서 포함). 통과한 것이 없으면 "유효하지 않다"는 A 보고서가 결론 |

### 예측 먼저 (결과를 보기 전에 기록)
- **lead agent(Claude)**: 학계 결과(Lo·Mamaysky·Wang 2000, Bajgrowicz·Scaillet 2012)는 "일부 패턴은 이후 수익 분포에 정보가 있지만 비용 뒤 이익은 대개 사라진다".
  예측: 대부분 기각. 남는다면 추세·이동평균 쪽(사실상 모멘텀)이고, 반전형(헤드앤숄더·쌍바닥)과 피보나치는 위약과 차이 없음.
- **사용자**: 특정 패턴을 고르지 않고 지인 트레이더의 도구(위 5종)를 우선 검증 대상으로 지정. 실전 트레이더가 쓰는 도구라는 점을 근거로 봄.

## 1. 단계와 verifier (② 공통 바탕 — 2026-11-18 사용자 승인, 구간만 50/50으로 수정)

| 단계 | 하는 일 | verifier | 통과 기준 |
|---|---|---|---|
| A0 탐지기 | 도구·패턴을 코드로 정의 (고점·저점 찾기 → 모양 규칙) | **합성 검사**: 가짜 가격에 패턴을 심어 찾는지(재현율), 무작위 보행에서 얼마나 자주 "찾는지"(기저 발생률). **잘라내기 검사**: 패턴 확정일 t까지만 데이터를 주고 다시 탐지해 같은 결과인지 (미래참조 차단). 사용자 육안 확인용 차트 표본 | 심은 패턴 재현율 ≥ 90%, 잘라내기 검사 불일치 0건, 육안 표본 사용자 확인 |
| A 유효성 | 신호일 t 다음 봉 시가 진입 가정, 이후 **20봉 수익률(주 지표, 사전등록)** 과 5·60봉(참고) | **위약 비교**: 같은 신호 날짜·같은 유니버스의 **다른 종목**(2026-11-18 사용자 승인으로 "같은 종목·같은 연도"에서 변경 — 같은 종목 위약은 신호의 가격 경로와 겹쳐 헛발견을 냄), 그리고 직전 60봉 수익률 5분위까지 맞춘 위약(모멘텀 효과 분리). 판정 p는 날짜 묶음·20봉 블록 Holm 둘 다. 날짜 묶음 부트스트랩(같은 날 몰린 신호의 상관 반영)으로 p값. **헛발견 검사**: 무작위 보행 가짜 시장 전체를 같은 파이프라인에 넣어 "유효" 판정이 거의 안 나오는지 | 아래 A 통과 기준 |
| B 전략화 | A 통과 도구마다 진입·손절·목표가가 있는 lab | `labs/README.md` 고정 기준 7개 + validator | 고정 기준 그대로 |

### A 통과 기준 (도구·패턴 × 시장 × 시간 축마다)
1. 탐색 구간에서 20봉 초과수익(신호 − 추세 맞춘 위약)이 Holm 보정 후 유의(α = 0.05). 보정 대상 = 이번 라운드의 모든 (도구 × 방향 × 시장 × 시간 축) 조합.
2. 초과수익 > 왕복 비용 (엔진 기본값 기준 KR 약 0.4%, US 약 0.6%).
3. 확인 구간에서 같은 부호이고 크기가 탐색 구간의 50% 이상.
4. 표본 ≥ 100건 (탐색 구간).

### noise floor
위약을 시드만 바꿔 20번 뽑아 초과수익 추정치가 흔들리는 폭(표준편차)을 잰다. 이보다 작은 차이는 효과로 보지 않는다.

### 데이터 구간
- 잠금 구간(실행일 기준 최근 6개월)은 A에서도 읽지 않는다 (`autotrader.backtest.data.load()` 기본 동작).
- A 단계는 개발 구간(2010-01-04 ~ 2026-05-18, 실행일 2026-11-18 기준)을 시간순으로 **탐색 50% / 확인 50%** 로 나눈다 (2026-11-18 사용자 결정).
  경계 = **2018-03-12** (신호일 기준). 20봉 뒤 수익이 경계를 넘는 탐색 구간 신호는 빼서 두 구간이 겹치지 않게 한다.
  도구 정의·파라미터는 탐색 구간에서만 정하고, 확인 구간은 라운드당 한 번 본다. (B lab은 `labs/README.md`의 워크포워드를 그대로 쓴다.)
- B lab에는 L003을 `trials.exposed_from`에 적는다. 이동평균 교차는 L002(US 상위 10 · 10/20일 교차, 대기)와 겹치므로 서로의 노출로 기록한다.

### 미리 알려진 한계
- US는 현재 구성종목만 있어 "바닥 패턴 뒤 반등"이 부풀려질 수 있다. 같은 종목 위약과 비교하면 상당 부분 상쇄되지만 완전하지 않다 → US 결과는 KR 결과의 보조로 본다.
- 패턴 정의(고점·저점의 크기, 어깨 높이 허용 오차 등)는 사람마다 다르다. 정의를 여러 개 시도할수록 다중 검정이 커지므로, 라운드 1은 문헌의 표준 정의 하나씩만 사전등록한다.
- B(신호형 lab)는 1회 주문 상한 처리 방식이 미결(`docs/dev-backlog.md`)이다. B 착수 전에 개발·점검 HQ 결정이 필요하다.

## 2. 라운드 1 brief (subagent 공통 지시) — 2026-11-18 확정

**목표**: KR·US 일봉·주봉에서 우선 검증 도구 5종의 A0 탐지기와 A 유효성 결과를 낸다.

**사전등록 정의 (라운드 1)** — 신호일 t는 패턴이 "확정"된 봉, 진입은 t+1 시가.

| 도구 | 롱 신호 | 숏(하락) 신호 | 정의 출처 |
|---|---|---|---|
| 이동평균 | 종가가 200일(주봉 40주)선을 상향 돌파 / 50·200 골든크로스 | 하향 돌파 / 데드크로스 | 고전 (Brock·Lakonishok·LeBaron 1992) |
| 피보나치 되돌림 | 직전 상승 스윙의 38.2~61.8% 되돌림 구간에서 반등 확인(구간 안 저점 뒤 양봉 종가 > 전일 고가) | 대칭 | 고전 (스윙 = 고점·저점 탐지기 출력) |
| 헤드앤숄더 | 역HS 넥라인 상향 돌파 | HS 넥라인 하향 돌파 | Lo·Mamaysky·Wang 2000 정의 |
| 쌍·삼중바닥 | 두(세) 저점 차 ≤ 1.5%, 사이 고점 상향 돌파 | 쌍·삼중천장 대칭 | Lo·Mamaysky·Wang 2000 / Bulkowski |
| 추세선 | 하락 추세선(고점 3개 이상 접점) 상향 돌파 | 상승 추세선 하향 돌파 | 고전 |

- 고점·저점 찾기: 커널 평활 후 극값(Lo 외 2000) 또는 ATR 배수 지그재그 중 하나를 탐지기 담당이 고르고 근거를 적는다. **극값은 확정 시점까지 미래 봉을 쓰지 않는다** (잘라내기 검사로 확인).
- 유니버스: KR = 그날 기준 시가총액 상위 500 중 20일 평균 거래대금 10억 원 이상(그날 알 수 있는 값). US = `us_1d` 전체(S&P500 + Nasdaq100 현재 구성).
- 숏 신호는 "하락 예측력"으로만 본다 (KR 개별주 공매도 실전 불가 → B에서는 매도·회피 신호로 씀).

**산출물 위치**: `labs/L003-chart-patterns/` 안 (`patterns/` 탐지기, `study/` 유효성, `results/A/`). 엔진·데이터 코드는 고치지 않는다.

**금지**: 잠금 구간 읽기, 확인 구간을 보고 정의 바꾸기, verifier·통과 기준 바꾸기, `labs/L003-chart-patterns/` 밖 파일 수정.

**보고 형식**: 도구 × 방향 × 시장 × 시간 축 표 — 표본 수, 20봉 초과수익(위약 대비, %), noise floor, Holm 보정 p값, 확인 구간 값, 통과 여부.

**배분 (③)**: 분업. subagent 1 = A0 탐지기 + 합성·잘라내기 검사 / subagent 2 = A 유효성 하네스 + 위약·부트스트랩·헛발견 검사 (탐지기 인터페이스만 약속하고 가짜 탐지기로 먼저 검증). 둘이 끝나면 lead agent가 합쳐 실행·재현하고, validator가 결과를 깨 본다. 동시 실행 상한 3.
