- 판정 반영: 8회 + 후보 선택(R2·H3b·H4 중 탐색 최선, 보유 기간 20→60봉은 R2 결과를 본 뒤 정함) + 1650 사전등록 규칙(블록 p ≥ 0.05면 확인 구간 안 엶)을 H4가 넘지 못했는데 "H5"로 이름을 바꿔 연 경위(사용자 결정, 기록은 투명함) → 블록 p 0.030은 경계선 결과로 보고 보류 이하로 판단. Bonferroni ×8 이면 0.24.

## 약세 논거 (운이거나 편향일 이유)
1. **KR(생존편향 없음)만으로는 불통과.** 전체 상위 20% 중 KR: +1.34%, 날짜 p 0.073, 블록 p 0.41, 연도 묶음 p 0.37. KR 단독으로 다시 상위 20%를 골라도 +0.55%, 블록 p 0.67. KR 일봉은 음수(−1.01%, 시장 단독 −0.71%). KR 월별 상위 K개 포트폴리오(K=5·10·20) Newey-West t 0.27~1.26, 중앙값 −3 ~ −13%.
2. **US 효과 = 생존편향 구간.** US에서 모델 예측은 시총 순위와 강하게 반대(스피어만 −0.70, 상위 신호 시총 백분위 중앙값 0.15 = 517종목 중 그때 작은 쪽). US 상위 20%를 시총 백분위로 나누면 하위 20%(그때 가장 작음) +5.54%, 나머지 구간 −2.6 ~ −8.5%. **그때 작지 않던 종목(시총 백분위 ≥ 0.2)만 놓고 보면 상위 20% 비용 후 US 일봉 −1.39%, 주봉 −4.38%, IC +0.011.** "지금 S&P500·Nasdaq100에 있는 작은 종목" = 나중에 커져서 편입된 종목(MSTR·TSLA·RKLB·COIN·SMCI·VRT·BE 등)이라, 이 효과는 미래 정보(현재 구성종목 명단)에서 나온다. 모델 없이 "변동성 상위 20%"만 사도 US 주봉 +12.0%(모델 +12.1%)이고 같은 규칙이 KR 주봉에서는 −6.3%다. 탐색 구간도 같은 구조(US 상위 중 55%가 시총 하위 20%, 그 구간 +3.69% vs 나머지 +1.20%, KR 일·주 모두 음수).
3. **꼬리 의존.** 전체 중앙값 −3.23%, 1~99% 윈저화 +0.06%, 양쪽 1% 잘라낸 평균 −0.75%, 2.5% 잘라내면 −1.58%. 상위 1% 거래가 순이익 합의 189%. 기여 상위 5·10·20종목을 빼면 +0.86 / +0.27 / −0.61%. KR은 상위 10종목이 순이익의 295%, 나머지는 −2.66%. 종목별 평균의 중앙값: KR −7.52%, US −1.97%.
4. **실전 포트폴리오에서 재현 안 됨.** 상위 30,048건은 같은 종목에 겹친 신호가 많다(TSLA 82건, WDC 108건 등). 종목당 보유 중에는 새 신호를 무시하고 한 번만 사면 5,261건, 평균 −0.34% (KR −0.27%, US −0.39%). 상위 20% 안에서 달마다 10종목을 무작위로 담는 시뮬레이션 1,000회: 평균 +0.28%, 5~95% 구간 −2.08 ~ +2.94%, 손실 확률 45%. 반대로 예측 최상위 K개는 +11 ~ +31%로 크지만 K=10이면 940건 중 US 주봉 796건(시총 백분위 중앙값 0.09)이라 2번의 생존편향이 그대로 증폭된 것.
5. **블록 p가 충분히 보수적이지 않음.** 주봉 60봉(≈14개월) 블록은 420일 고정 구간이라 확인 구간 8년에 블록 8개뿐이고, 이웃 블록끼리 보유 기간이 겹친다. 정규 근사 대신 t(df=K−1)를 쓰면 US 주봉 블록 p 0.026 → 0.061. 일봉·주봉, KR·US를 서로 다른 블록으로 취급해 같은 기간의 공통 충격이 독립으로 세어진다. 그래도 전체로는 연도 묶음 t p 0.029, 종목 묶음 p 0.021, 월별 코호트 Newey-West p 0.013으로 비슷한 경계선 수준 — 시도 8회를 감안하면 약함.
6. **임계값 ±20% 민감.** 상위 기준 분위 0.76(−20% 쪽 해석)이면 +1.13%, 블록 p 0.113으로 불통과. 0.84 이상에서는 좋아지지만 위 2·3번의 꼬리·US 주봉 몰림이 커질 뿐 KR은 0.95에서 −2.10%.
7. 시간 집중: 연도별 상위 20%는 2019(+5.31%)·2021(+4.65%)에 크고 2024는 −1.39%. KR 주봉은 2024 −6.81%, 2025 −21.59%.

## 발견한 문제와 재현 명령
1. KR 단독 불통과 / US 시총 하위 20% 밖 음수 / 꼬리·겹침 제거 시 음수 — 아래 스크립트로 재현 (worktree 루트에서 `uv run python <파일>`, 데이터 디렉터리 불필요).
   ```python
   import pandas as pd, numpy as np
   L='labs/L003-chart-patterns/'
   d=pd.read_parquet(L+'results/R3/20261118-1901-confirm-rg-h60-hgb/predictions.parquet')
   f=pd.read_parquet(L+'model/.cache/dataset_v2_both_real_kr-us_h60_2026-05-18.parquet')
   k=['market','timeframe','sym','date','tool','variant']
   d=d.merge(f[f.period==1][k+['mcap_rank','vol_20']],on=k,how='left')
   d['net']=d.y-d.cost60; t=d[d.pred_hgb_s0.rank(pct=True)>0.8]
   print(t.groupby('market').net.mean())                          # KR +1.34%, US +1.96%
   u=t[(t.market=='us_stock')&(t.mcap_rank>=0.2)]; print(u.groupby('timeframe').net.mean())  # 1d −1.39%(시장 단독 상위), 1w −4.38%
   from scipy.stats import trim_mean; print(trim_mean(t.net,0.01))  # −0.75%
   # 종목당 한 번만 보유: 종목별 날짜순으로 직전 진입의 exit60 이후 신호만 채택 → 5,261건, −0.34%
   ```
   블록 p는 `walkforward.block_key`(일봉 84일·주봉 420일)와 같은 묶음에 2000회 부트스트랩, t(K−1) 근사 병행.
2. 1650 사전등록 규칙과 H5의 관계: H4는 탐색에서 블록 p 0.05~0.41로 규칙상 확인 구간을 열 수 없었고, 사용자 결정으로 H5로 새로 등록해 열었다 (log 1900·1920). 절차 기록은 투명하지만 선택 편향이 남는다.
3. 시드 noise floor: 탐색 5시드 비용 후 +0.54 ~ +1.60%(폭 약 1%p) → 확인 결과 +1.78%는 시드 하나 값이라 noise floor 대비 여유가 크지 않다. 다른 시드 확인은 **재학습이 필요하다** (확인 구간을 다시 보는 것이므로 이번에는 하지 않음, 하려면 시도 +1로 기록해야 함).
