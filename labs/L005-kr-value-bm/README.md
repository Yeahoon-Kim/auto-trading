# L005 — KR 가치: 장부가/시가(B/M) 상위 20%

고전 퀀트 프로그램 1번째 기법 ([docs/research/2026-11-18-classic-quant-factors.md](../../docs/research/2026-11-18-classic-quant-factors.md) 5절).

## 1. 타겟 시장
- 시장 / 유니버스 / 타임프레임: KR 주식 KOSPI+KOSDAQ (상장폐지 포함) / 일봉, 월 1회 리밸런싱
- 유니버스 (프로그램 공통, 사전 고정): 보통주(코드 끝 0), 원본 종가 ≥ 1,000원, 20일 평균 거래대금 ≥ 10억 원, 가격 이력 ≥ 252거래일, 그날 거래(거래량 > 0)
- 이 시장을 고른 이유: KR은 `krx_1d`(상장폐지 포함)와 `dart_fin`(공개일 다음 거래일 규칙)으로 생존편향·미래참조 없이 재무 요인을 시험할 수 있다. US는 현재 구성종목만 있어 종목 선택 전략을 판정할 수 없다.

## 2. 전략 — 백테스트 실행 전에 작성하고 커밋
- 작성일: 2026-11-18
- **가설**:
  1. 투자자는 최근 부진하거나 성장성이 낮아 보이는 기업을 지나치게 비관적으로 평가한다(과잉반응, Lakonishok·Shleifer·Vishny 1994). 또는 싼 주식은 위험이 커서 보상받는다(Fama-French 1992). 어느 쪽이든 장부가 대비 싼 종목(B/M 상위)이 이후 더 높은 수익을 낸다.
  2. 한국에서 가치 프리미엄은 2005년 이후 더 강하다는 연구가 있다 (Jang 2024). 따라서 KR 2018~2026 시험 구간에서 **같은 유니버스 동일가중보다 높은 수익**을 기대한다.
  3. 롱 온리라 수익 대부분이 시장 베타다. 사전 예측: **기준 1(Sharpe ≥ 1.0)은 못 넘고**, 동일가중·무작위 대비 초과 여부가 핵심 관찰이다.
- 출처: Fama & French (1992, 1993), Lakonishok, Shleifer & Vishny (1994), Asness & Frazzini (2013, 매월 최신 가격으로 B/M 갱신)
- 진입 규칙 (매월 첫 거래일 종가 기준 계산, 다음 거래일 시가 체결):
  1. 후보: 위 공통 유니버스
  2. 점수: B/M = `equity`(자본총계, 최근 공개 분기말, 연결이면 비지배지분 포함) / `market_cap`(그날 종가 기준 종목 시가총액). 자본 ≤ 0이거나 재무가 없는 종목은 제외
  3. 점수 상위 20%(후보 수 × 0.2, 내림)를 동일 비중으로 보유
- 청산 규칙: 다음 달 첫 거래일에 상위 20% 밖이면 매도. 상장폐지는 엔진이 마지막 가격 다음 봉에 청산.
- 실행 유형: portfolio. `rebalance: on_signal` (월초에만 전 종목을 목표 비중으로)
- 파라미터 (문헌·프로그램 공통값, 개발 구간을 보고 고르지 않음): quantile 0.2 (5분위), min_value 10억, liq_days 20, min_price 1,000, min_hist 252
- 데이터 시점: 재무는 `fin_timing: first`(사업·분기보고서 최초 접수일 다음 거래일부터, 정정 값이 최초 접수일부터 보이는 경미한 미래참조 — validator 확인 대상)
- 알려진 단순화: 시가총액은 보통주 코드 기준이라 우선주가 있는 회사는 B/M이 약간 높게 나온다. 금융업을 따로 빼지 않는다(은행·금융지주는 `dart_fin`에 없어 자동 제외, 보험·증권은 포함).
- 사전에 정한 비교 (`baseline.py`, 같은 시험 구간·같은 비용): KOSPI 지수(가격지수, 비용 없음, 참고) / 같은 유니버스 전체 동일가중 / 같은 유니버스에서 같은 종목 수를 매월 무작위로 뽑은 포트폴리오 100회
- 워크포워드: 2016-04-01 시작, 학습 24개월 / 시험 6개월 → 시험 2018-04 ~ 2026-05 (잠금 구간 전까지)
- `trials.exposed_from: [L001]` — 같은 KR 개발 구간을 L001이 먼저 봤다 (프로그램 장부).
