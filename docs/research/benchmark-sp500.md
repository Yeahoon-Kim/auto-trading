# 벤치마크: S&P500 매수 후 보유

모든 lab이 넘어야 할 기준선입니다. "그냥 S&P500을 사서 들고 있었으면 얼마였나"를 계산합니다.

- 코드: `src/autotrader/backtest/benchmark.py`
- 다시 만들기: `uv run python -m autotrader.backtest.benchmark`
- 결과 파일(git 제외, 다시 만들 수 있음): `results/benchmarks/sp500/`
  - `summary.csv`: 변형 × 구간(full/dev/lockbox) × 비용 포함 여부별 지표
  - `summary_cost2x.csv`: 비용을 2배로 올린 결과
  - `yearly.csv`: 연도별 수익률 (비용 포함)
  - `equity.parquet`: 일별 자산 곡선 (비용 포함, 시작 = 1.0)
- lab에서 쓰는 법: `from autotrader.backtest.benchmark import benchmark_returns` →
  `benchmark_returns("SPY_tr_wht", start, end)`로 일간 수익률(비용 전)을 받습니다.

## 조건

| 항목 | 값 |
|---|---|
| 기간 | 2010-01-05 ~ 2026-11-13 (VOO만 2010-09-10부터, 상장일 기준) |
| 데이터 | Yahoo 일봉(`us_1d` SPY·IVV·VOO, `macro_1d` SPX), 원/달러는 한국은행 ECOS 매매기준율 |
| 매매 | 첫날 종가에 매수, 마지막 날 종가에 매도 (거래 2회) |
| 비용 | **포함.** 한 번 거래할 때 0.30% (수수료 0.25% + 슬리피지 0.05%, `config/settings.yaml`). 2배 비용 결과는 별도 파일 |
| 배당 | `SPY_tr`은 배당 전액 재투자, `SPY_tr_wht`는 미국 원천징수 15%를 떼고 재투자 |
| Sharpe | 무위험금리를 뺀 값. 달러는 연방기금금리(FRED DFF), 원화는 CD 91일(ECOS). 둘 다 하루 늦춰 씀 |
| 반영 안 함 | 해외주식 양도소득세(22%, 연 250만원 공제), 배당소득 종합과세, 환전 수수료 |

**기준으로 쓸 값: `SPY_tr_wht`** (한국 거주자가 달러로 SPY를 보유한 경우). 원화로 운용하는 전략과 비교할 때는 `SPY_tr_wht_krw`를 씁니다.

## 결과 (전체 기간, 비용 포함)

| 변형 | 설명 | CAGR | 변동성 | Sharpe | MDD | 최장 회복(거래일) |
|---|---|---|---|---|---|---|
| SPX_price | 가격지수, 배당 없음 (참고용) | 11.90% | 17.2% | 0.65 | -33.9% | 512 |
| SPY_price | SPY 가격만 | 11.88% | 17.1% | 0.65 | -34.1% | 512 |
| SPY_tr | 배당 재투자 | 13.86% | 17.1% | 0.76 | -33.7% | 488 |
| **SPY_tr_wht** | **배당 원천징수 15% 반영** | **13.56%** | **17.1%** | **0.74** | **-33.8%** | **488** |
| SPY_tr_wht_krw | 위 값을 원화로 환산 | 14.46% | 18.7% | 0.69 | -30.1% | 214 |
| IVV_tr | 교차 확인 | 13.88% | 17.2% | 0.75 | -33.9% | 488 |
| VOO_tr | 교차 확인 (2010-09~) | 14.62% | 17.0% | 0.80 | -34.0% | 488 |

- MDD는 모두 2020-03-23(코로나 폭락)입니다.
- 비용 영향은 작습니다. 거래가 2회뿐이라 비용을 2배로 올려도 `SPY_tr_wht` CAGR은 13.56%에서 13.52%로만 줄어듭니다.
- SPY·IVV·VOO가 서로 0.05%p 안에서 일치하고, 연도별 수익률도 공개된 SPY 총수익률과 맞습니다(2022년 -18.2%, 2024년 +24.9%).
- 원화 환산은 원화 약세 덕분에 CAGR이 더 높고 MDD가 더 얕습니다. 위기 때 달러가 오르면서 손실을 일부 메워 줬기 때문입니다.

## 전략에 주는 의미

**검증 기준 1번(Sharpe 1.0 이상)이 시장보다 높습니다.** 그냥 보유한 S&P500의 Sharpe가 약 0.74라서, 기준을 통과한 전략은 위험 대비 수익에서 시장을 이긴 셈입니다. 반대로 Sharpe가 0.74보다 낮은 전략은 CAGR이 높아 보여도 지수를 보유하는 편이 낫습니다.

lab README의 "벤치마크 대비" 칸에는 같은 기간으로 자른 `SPY_tr_wht`의 CAGR, Sharpe, MDD를 적습니다.

## 잠금 구간

`summary.csv`에는 잠금 구간(2026-05-15 ~ 2026-11-13) 행도 있습니다. 벤치마크는 전략이 아니라서 잠금 규칙의 대상은 아닙니다. 하지만 최근 6개월 시장 흐름을 알고 나면 전략 설계가 그쪽으로 기울 수 있으니, **개발 중에는 `period == "dev"` 행만 보세요.** 잠금 구간 행은 판정 단계에서 전략의 잠금 구간 결과와 나란히 놓고 비교할 때 씁니다.

## 점검

- **생존편향: 없음.** 개별 종목이 아니라 지수와 ETF를 쓰기 때문에, 편입·편출이 지수 안에서 처리됩니다.
- **미래참조: 없음.** 신호가 없는 매수 후 보유입니다. 무위험금리는 하루 늦춰 쓰고, 환율은 같은 날 뉴욕 종가보다 먼저 고시되는 서울 매매기준율을 씁니다.
- **데이터 한계**
  - Yahoo `adj_close`는 배당을 사후에 반영한 값이라, 데이터를 다시 받으면 과거 값이 아주 조금 바뀔 수 있습니다.
  - Yahoo 원/달러(`macro_1d/USDKRW`)에는 하루 만에 되돌아오는 이상 틱이 있어 쓰지 않았습니다(일간 변동성 11.2%, 월간 9.5%). 다른 분석에서 이 시계열을 쓸 때도 주의가 필요합니다.
  - 2010년 이전 데이터가 없어서 2008년 금융위기가 기간에 들어 있지 않습니다. 그래서 MDD -34%는 장기 평균보다 낙관적인 값일 수 있습니다.
