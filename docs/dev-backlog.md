# 개발 대기열 (개발·점검 HQ)

> 운용 방식은 [operating-model.md](operating-model.md) 5절. 전략부·사용자가 엔진·데이터·운영 요청을 여기에 적고, 개발·점검 HQ가 작업 세션에 배정한다.
> 전략 아이디어는 여기가 아니라 [labs/BACKLOG.md](../labs/BACKLOG.md)에 적는다.

## 형식

| 칸 | 내용 |
|---|---|
| 요청 | 한 줄 |
| 영역 | 백테스트 엔진 / 데이터 수집 / 리스크·실행 / 시장정보·운영 / 테스트·문서 |
| 요청자 | 사용자 / 전략부 / 개발부(점검에서 발견) |
| 상태 | 결정 대기 / 대기 / 진행(브랜치) / 완료(커밋) |
